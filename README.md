## 🎯 프로젝트 개요

Piece Service는 **실물자산 조각 거래**의 핵심 서비스로, 조각 생성부터 실시간 거래까지 모든 기능을 제공합니다.

### 🌟 주요 특징

- **조각 생성**: 공모 완료 후 자동 조각 생성 및 분배
- **실시간 거래**: 조각 매수/매도 거래 시스템
- **동시성 제어**: Redis 분산 락을 통한 안전한 거래 처리
- **실시간 시세**: SSE를 통한 실시간 호가 및 체결가 스트리밍
- **소유권 관리**: 조각별 소유자 추적 및 보유 현황 관리

### 🏆 핵심 역할

- **조각 관리**: 조각 생성, 분배, 소유권 관리
- **거래 처리**: 매수/매도 주문 처리 및 체결
- **실시간 데이터**: 호가, 체결가, 거래량 실시간 업데이트
- **포트폴리오**: 사용자별 보유 조각 관리

## 🛠️ 기술 스택

### Backend
- **Java 17** - OpenJDK LTS 버전
- **Spring Boot 3.5.0** - 최신 Spring Boot 프레임워크
- **Spring WebFlux** - 반응형 웹 프레임워크
- **Spring Data JPA** - ORM 및 데이터 접근 계층

### Database & Cache
- **MySQL 8.0** - 메인 데이터베이스
- **Redis 7.0** - 분산 락 및 실시간 데이터 캐시
- **Redisson** - Redis 분산 락 구현

### Message Queue & Streaming
- **Apache Kafka** - 이벤트 기반 통신
- **Server-Sent Events (SSE)** - 실시간 데이터 스트리밍
- **Spring Cloud Stream** - 스트림 처리

### Service Discovery & Documentation
- **Netflix Eureka Client** - 서비스 디스커버리
- **OpenFeign** - 서비스 간 HTTP 통신
- **SpringDoc OpenAPI 3** - API 문서화

### Infrastructure
- **Docker** - 컨테이너화
- **AWS EC2** - 클라우드 배포

## 🚀 주요 기능

### 1. 조각 생성 및 분배
- **조각 생성**: 총량에 따른 조각 생성
- **자동 분배**: 공모 참여자에게 조각 분배

### 2. 실시간 거래 시스템
- **분산 락 제어**: Redis를 통한 동시성 제어
- **거래 처리**: 매수/매도 주문 처리
- **체결 시스템**: 호가 매칭 및 거래 체결
- **실시간 업데이트**: 거래 완료 시 실시간 알림

### 3. 실시간 시세 스트리밍
- **SSE 연결**: 실시간 가격 정보 스트리밍
- **초기 데이터**: 연결 시 현재 가격 정보 전송
- **자동 정리**: 연결 종료 시 자동 구독 해제

### 4. 호가 정보 조회
- **Redis 캐시**: 호가 정보 빠른 조회
- **자동 재생성**: 캐시 미스 시 DB에서 재생성
- **실시간 업데이트**: 거래 시 호가 정보 자동 업데이트

## ⚙️ 환경 설정

### 필수 요구사항
- Java 17 이상
- MySQL 8.0 이상
- Redis 7.0 이상
- Kafka 3.0 이상
- Docker (선택사항)

### 환경 변수
- **DATABASE_URL**: MySQL 데이터베이스 연결 정보
- **REDIS_URL**: Redis 서버 연결 정보
- **KAFKA_BOOTSTRAP_SERVERS**: Kafka 서버 정보
- **EUREKA_CLIENT_SERVICE_URL**: Eureka 서버 정보

## 📚 API 문서

### Swagger UI 접속
API 문서는 Swagger UI를 통해 확인할 수 있습니다.

### 주요 API 엔드포인트

#### 조각 관리
- **조각 목록 조회**: 전체 조각 목록 조회
- **조각 상세 조회**: 특정 조각 상세 정보 조회
- **조각 생성**: 새로운 조각 생성
- **조각 정보 수정**: 조각 정보 업데이트

#### 거래 관리
- **거래 주문 생성**: 매수/매도 주문 생성
- **거래 주문 목록**: 사용자별 거래 주문 목록 조회
- **거래 주문 상세**: 특정 거래 주문 상세 조회
- **거래 주문 취소**: 미체결 거래 주문 취소

#### 실시간 데이터
- **실시간 가격 스트림**: SSE를 통한 실시간 가격 정보
- **호가 정보 조회**: 현재 매수/매도 호가 정보
- **거래 내역 조회**: 최근 거래 내역 조회

#### 포트폴리오
- **보유 조각 목록**: 사용자별 보유 조각 목록
- **포트폴리오 요약**: 총 자산 및 수익률 요약
- **수익률 분석**: 개별 조각별 수익률 분석

## 🔧 주요 설정

### 분산 락 설정
Redis를 통한 분산 락으로 동시성 문제를 해결합니다.

SSE를 통한 실시간 데이터 스트리밍이 설정되어 있습니다.

Kafka를 통한 이벤트 기반 통신으로 다른 서비스와 연동됩니다.
